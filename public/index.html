Station Sensors→ Local Buffer→ Satellite Sync Layer→ Digital Twin Model→ Forward Simulation→ Autonomous Action / MoES Dashboard

The twin isn't just a live display — it's a model of each station's resource state that gets simulated forward against a fixed, known constraint: the resupply calendar. Antarctic stations can't resupply on demand, only in scheduled windows, so a shortfall predicted even weeks out is a real risk. When the projection crosses that line, the system takes a conservation action automatically (reducing non-essential load) — and only escalates to a human alert alongside it. That's the difference between monitoring and automation.
